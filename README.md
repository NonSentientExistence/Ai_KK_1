# Väder och luftkvalitet för KK1

## Dataset
World Weather Repository av nelgiriyewithana, hämtat från Kaggle.
Innehåller väder- och luftkvalitetsmätningar från städer världen över.
142 093 rader, mätstart 2023-08-29.

Källa: https://www.kaggle.com/datasets/nelgiriyewithana/global-weather-repository

## Hur notebooken körs
1. CSV ligger i dataset mappen, annars ladda ner datasetet från länken ovan.
2. Om CSV hämtas från länken, lägg CSV-filen i en mapp vid namn `dataset/`
3. Kör `notebook.ipynb` uppifrån och ner
